# Deskvanic 产品规格（PRODUCT_SPEC.md）

## 定位

**Deskvanic — Your Mac. One workspace.**
macOS 原生多功能效率平台：一个统一入口，多个真正可靠的工具，跨工具的完整工作流。
本地优先 · 无强制登录 · 模块可独立启停 · 零第三方依赖（全 Apple 系统框架）。

## 目标用户

日常用户 / 学生 / 办公人员 / 内容创作者 / 常处理图片文档截图者 / 跨设备传文件者 / 收藏整理者 / 效率工具爱好者。

## 三种核心入口

1. **主窗口**：首页（工具卡片+最近任务）+ 侧边栏分组（高频/文件资料/系统能力/进阶）。
2. **全局命令面板**（⌃⇧Z 可配）：搜索并执行命令/应用/授权文件/资料；`>` 仅搜命令，`app ` 仅搜应用。
3. **菜单栏图标**：快速打开、设置、退出（随模块启用扩展：暂停监控等）。

## 非目标（当前版本）

- 不做云同步/账号体系（本地优先）
- 不做 Windows/iOS 原生端（NearLink 浏览器方案覆盖移动侧）
- 不提供任意 Shell 脚本执行节点（安全边界）
- 不内置大模型（OCR/语音用系统能力）
