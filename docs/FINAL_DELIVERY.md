## 1. Deskvanic 现在实际有哪些功能？

15 个模块全部有真实功能闭环（无占位按钮、无 Mock 数据、无"开发中"入口——独立审计 Agent 全工程 grep 验证）：

| 模块 | 现在就能做的事 |
|---|---|
| 全局命令中心 | ⌃⇧Z 唤出面板，搜索并执行命令/已装应用/授权目录文件/资料库条目；最近与收藏持久化 |
| 剪贴板 | 文本/URL/图片/文件历史自动入库、去重、固定收藏、纯文本粘贴、模拟⌘V、模板、保留期清理、暂停/排除应用 |
| 截图 | 区域（拖拽框选）/窗口/全屏截图，Vision 本机 OCR（中英）、条码识别、标注（裁剪/矩形/箭头/文字/**真像素模糊**）、固定悬浮窗、历史 |
| 文件处理 | 拖拽暂存+排序缩略图、图片 4 格式转换/缩放/压缩（二分质量）/GPS·IPTC 剥离（输出复核）、PDF 合并/拆分/旋转/提取/优化（如实报告副作用与达成率）、ZIP 打包解压（穿越/炸弹/CRC 防护）、批量重命名（冲突检测）、处理模板 |
| 资料库 | 文本/链接/图片/PDF 收藏（复制进库或引用原路径双模式、失效状态明示）、标签、OCR 全文检索、PDF 预览、备份 |
| 快捷工具 | 文本清理/替换（正则+全词）/大小写/行操作（自然排序）、Markdown 安全渲染、LCS 对比、二维码生成解析、颜色 5 格式、表达式计算器（Decimal 模式）、10 类单位换算、计时器、番茄钟 |
| 整理 | 卷空间可视化、大文件 TopN、完全重复（全量 SHA-256）、相似图片（aHash 汉明距离）、分类整理（模拟运行→冲突报告→确认→同卷 rename/跨卷废纸篓）、防重复触发、审计记录 |
| 互传 | 局域网 HTTP 服务器 + 128bit 令牌 + 二维码邀请，手机浏览器上传/下载/发文本，传输记录 |
| 工作空间 | 捕获当前窗口布局、一键启动应用组并恢复窗口位置（AX API，未授权明确提示） |
| 语音 | 录音（引擎就绪）、音频文件导入转写、用户词典、自动标点、转写历史、插入前台应用 |
| 教程 | 步骤截图（自动序号标注）、时间线编辑、敏感信息 OCR 启发式扫描、导出 Markdown/单文件 HTML/PDF |
| 票据 | 凭证导入复制进库、OCR 预填金额/日期/商户（标记待核实）、人工核实编辑器、到期提醒（通知授权）、全文检索 |
| 网页资料库 | URL 收藏（规范化去重）、标题/描述抓取（GB18030 支持）、正文启发式提取、阅读清单、导出 JSON、转入资料库 |
| 媒体 | 音视频裁剪（输出时长校验）、提取音频、WAV/AIFF/M4A 转码、GIF 生成（帧率/尺寸参数）、波形显示 |
| 工作流 | 动作节点串联（端口类型检查+参数校验）、**连接 13 种真实业务动作**、模拟运行、节点超时/重试/取消、文件夹事件触发、导入导出 |

## 2. V1、V2、V3 各完成了什么？

- **V1**（M01–M06）：六模块功能闭环 + 核心服务层（数据库 12 版迁移链、FTS、任务队列、事件总线、文件安全原语、权限中心、审计）+ 应用宿主与打包脚本。161 项测试。
- **V2**（M07–M10）：磁盘整理、网络互传、窗口工作空间、语音输入；系统权限路径全部打通（未授权明确降级）。181 项测试。
- **V3**（M11–M15）：教程生成、票据管家、网页资料库、媒体处理、FlowEngine（核心差异化，动作连接真实模块）。209 项测试 + 六条端到端工作流。

环境：Apple Silicon arm64 / macOS 27.0.1 / Debug 构建（数字保守）。数据：1 万条 FTS 文档、100 次检索采样、20MB ZIP、4000×3000×3 图片、1MB 文本。

## 8. 是否仍存在已知 Bug？

## 9. 哪些功能在特定 macOS 版本存在限制？

最低部署 macOS 14。限制详见 KNOWN_ISSUES：CGWindowListCreateImage 弃用警告（功能正常，ScreenCaptureKit 迁移列后备）、macOS 无 AVAudioSession（录音用默认输入）、无公开剪贴板来源 API（启发式归属）、JetBrains 式窗口状态不可恢复（系统限制，如实反馈）。

## 10. 哪些权限需要用户批准？

屏幕录制（截图/教程）、麦克风+语音识别（语音模块）、辅助功能（模拟粘贴/工作空间摆窗）、通知（票据到期提醒）。全部按需弹窗请求，未授权时功能明确降级并给出系统设置指引（无静默失败）。本地网络权限在 NearLink 首次启动时由系统自动弹出。

## 15. 如何构建、测试、升级和维护这个软件？

- 测试：`swift test`（215 项，3.7s）；E2E 在 `Tests/DeskvanicModuleTests/EndToEndTests.swift`

- 升级用户：应用内"数据 → 备份数据库"；迁移自动执行且有回滚与完整性检查
