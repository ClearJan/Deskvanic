### 开发中发现并修复的真实缺陷（全部有测试防复发）

1. **FTS 中文整段单 token**：unicode61 分词器把连续中文当一个词 → 子串查不到。修复：写入与查询双侧 CJK 逐字切分。（SearchIndexTests）
2. **符号链接逃逸误判**：`URL.resolvingSymlinksInPath` 对不存在末段不解析中间链接 → 防护失效。修复：逐组件手动解析。（pathContainmentSymlinkEscape）
3. **模糊匹配偏好长串**：compactness 权重使 "zipper" 排在 "zip" 前。修复：改为首字符位置优先。
4. **PDF 页旋转 API 误用**：PDFKit 无 setRotation → 属性赋值 + 归一化。
5. **批量重命名冲突漏检**：与"参与计划但未改名"文件的同名冲突未报。修复：目标计数 + 未改名占用双重检测。
6. **Calculator 分词**：`log2`/`log10` 被拆成 `log`+`2`。修复：标识符允许数字。
7. **替换模板泄漏**：字面量模式下 `$0` 被当模板解释。修复：非正则时转义模板元字符。
8. **灰度位图上下文 data 读取崩溃**：本 SDK 上 `CGColorSpaceCreateDeviceGray` 上下文缓冲直接读取 SIGTRAP。修复：aHash 改 RGB 亮度计算。
9. **正文提取闭合标签错配**：`prefix(7)` 拼接出 `<articl>`。修复：`"</" + tag` 构造。
10. **提取阈值误判**：46 字合法短文被 80 字阈值判失败。修复：降至 30 字。
11. **E2E OCR 裁切**：1200px 宽图放不下 64pt 长文本，OCR 只见 "19.00"。修复：按字数加宽画布（教训：OCR 输入质量先于断言）。
12. **Swift 6 并发系列**：actor deinit 限制（改显式 close）、NSLock 异步上下文禁用（改 OSAllocatedUnfairLock）、非 Sendable 回调跨域（回调内提取纯值）。
