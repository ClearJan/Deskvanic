## 设计层面的性能保障

1. **命令面板**：搜索防抖 120ms；静态命令内存匹配，应用列表缓存 300s，文件搜索缓存 60s；全部 actor 异步，不阻塞主线程。
2. **剪贴板监控**：0.5s 轮询（changeCount 整数比较，无可观开销）；入库在后台 Task。
3. **扫描类操作**：目录扫描深度/条目数上限（8000 条默认）、FTS 巨型查询护栏、diff 行数护栏。
4. **任务队列**：默认并发 2，长任务走 TaskQueue（OCR/转码/压缩），UI 保持响应；退出时有任务确认对话框。
5. **启动**：所有模块服务为惰性/轻量初始化；数据库 WAL 模式；迁移只在版本变化时执行。

## 已知性能注意点（如实记录）

- FTS 万条逐条写入为事务内逐条 upsert；未来可改为单事务批量（当前剪贴板/资料库写入频率下无实际影响）。
- GIF 生成与视频转码走 AVFoundation，耗时与素材长度线性相关，已置于任务队列并支持取消。
- 相似图片检测对每张图计算 aHash（O(n) 单次解码），万张图级别建议分批（当前上限保护 60,000 条目）。
